Votre code d'accès vous a été envoyé par mail. Il ouvre le portail — ajoutez-le à l'écran d'accueil de votre téléphone, il se comporte comme une application.

01Le principe en une page

Le service utilise un système de planning en ligne, accessible depuis n'importe quel navigateur (téléphone, tablette, ordinateur). En tant que MAR, vous avez quatre pages, chacune avec un rôle précis :

PageÀ quoi elle sertQuand vous en servir
PortailVotre page d'accueil personnalisée : vos prochaines gardes, vos congés, la veille biblio, les protocoles, l'annuaire…Tous les jours
PlanningConsulter le planning de l'équipe : gardes, secteurs du bloc, consultations, équité.Quand vous voulez savoir qui fait quoi
IndisponibilitésDéclarer vos indisponibilités et vos souhaits de garde avant la génération du planning de l'année suivante.Chaque automne (octobre-novembre)
Staff Vacances (en staff)Vos vacances et formations sont posées ensemble en réunion de staff, pas en ligne — vous n'ouvrez pas cette page. La priorité de votre groupe sert de départage.Chaque automne, au staff

Vous ne pouvez rien « casser » : ces pages sont soit en consultation seule, soit limitées à vos propres saisies. La gestion du planning (placements, échanges, corrections) reste entre les mains du comité.

Bon à savoir

Toutes ces pages fonctionnent sur téléphone. Ajoutez le portail à l'écran d'accueil de votre smartphone : il se comporte alors comme une application.

02Votre code d'accès

Un seul code personnel ouvre tout ce qui vous est propre : le portail et la saisie des indisponibilités. C'est le code que vous avez reçu par e-mail au lancement du système (et à chaque renvoi). (Le Staff Vacances, lui, se tient en réunion — voir section 07.)

  • Il est personnel : il identifie vos saisies et affiche vos informations (vos gardes, vos congés).
  • Il ne change pas d'une année sur l'autre, sauf renvoi par le comité.
  • Le planning en consultation, lui, est ouvert : pas de code pour regarder.
Code perdu ?

Pas de panique et pas de compte à recréer : demandez au comité de renvoyer votre code (c'est un bouton de leur interface, ils le font en quelques secondes). Vérifiez aussi vos indésirables : l'e-mail d'origine s'y cache parfois.

  • 🌗 bascule en mode sombre.
  • Une fois connecté, votre ligne est surlignée dans les vues Affectations et Année, et votre carte mise en avant dans Équité.
  • Sur téléphone, la barre du bas propose les mêmes cinq vues ; le Planning s'y lit jour par jour (flèches ← → et bouton 📍 Aujourd'hui), et la vue Affectations s'y appelle « Secteurs ».
Ce que vous voyez est ce qui est publié

Le comité travaille sur un brouillon puis publie. Le planning que vous consultez est toujours la dernière version publiée : si une modification vient d'être décidée mais pas encore publiée, elle n'apparaît pas encore.

Les semaines à venir & le badge 🚧

Vous voyez les semaines déjà passées et les quatre prochaines (semaine en cours jusqu'à trois semaines plus tard). Les semaines plus lointaines restent consultables mais portent un badge 🚧 provisoire : le comité peut encore les ajuster, elles ne sont pas définitives. La référence qui fait foi reste le fichier Excel envoyé par mail chaque vendredi pour la semaine suivante.

06Saisir vos indisponibilités

Chaque automne, avant que l'ordinateur ne répartisse les gardes de l'année suivante, la page Indisponibilités s'ouvre pour recueillir vos contraintes. C'est le moment où votre saisie influence directement votre futur planning de gardes.

Où la trouver

Pendant la campagne, une tuile « Mes indisponibilités » apparaît sur le portail, juste sous Planning : c'est le chemin le plus simple. Elle s'efface une fois le planning de l'année suivante généré. Le lien figure aussi dans l'e-mail qui annonce l'ouverture de la saisie.

Comment faire

  1. Depuis le portail, ouvrez la tuile « Mes indisponibilités » (ou la page directement) et saisissez votre code d'accès personnel.
  2. Choisissez un outil dans la barre : 🚫 Indisponible, ⭐ Garde souhaitée ou 🕐 Temps partiel.
  3. Touchez les jours du calendrier pour appliquer l'outil actif. Retouchez un jour pour le désélectionner.
  4. Terminez par 💾 Sauvegarder mes indisponibilités. Le message « ✅ Indisponibilités sauvegardées » confirme l'enregistrement.

Les trois marquages

MarquageEffet sur la répartition
🚫 IndisponibleAucune garde ne vous sera attribuée ce jour-là. À utiliser pour vos contraintes fermes (engagement familial, autre activité…).
⭐ Garde souhaitéeÀ l'inverse : vous préférez être de garde ce jour-là. L'ordinateur essaie d'en tenir compte, sans garantie absolue.
🕐 Temps partielVos jours non travaillés récurrents si vous êtes à temps partiel.
Quotas

Le nombre de jours d'indisponibilité et de jours de temps partiel est plafonné (le compteur s'affiche en haut de page). Si tout le monde bloquait ses week-ends, la répartition deviendrait impossible : le quota garantit que l'équité reste calculable.

Règle

Après la date limite annoncée par le comité, la saisie ferme et la génération se lance. Une indisponibilité saisie après coup n'est pas prise en compte par l'ordinateur : elle se règle alors par échange de gardes, à la main.

07Le Staff Vacances (comment vos vacances sont décidées)

Vos vacances et jours de formation ne se saisissent pas en ligne chacun de son côté : ils sont posés ensemble, en réunion de staff, à l'automne. Le comité projette l'écran « Staff Vacances » et remplit avec l'équipe les congés de chacun pour l'année à venir, période par période (hiver, printemps, été, Toussaint, Noël). Vous n'avez donc aucune page à ouvrir pour ça — venez au staff avec vos souhaits. Une fois les vacances verrouillées, vous saisissez vos indisponibilités chacun de votre côté (section 06).

Le principe des groupes

L'équipe est répartie en trois groupes (A, B, C). À chaque période de vacances, l'ordre de priorité entre groupes tourne : le groupe prioritaire sur Noël ne l'est pas sur l'été, et l'ordre change d'une année sur l'autre. Le tableau « Priorités vacances » en haut de page montre l'ordre de votre groupe pour chaque période.

Les seuils

Pour chaque jour, un nombre maximal de MARs absents est défini (le service doit tourner). L'écran projeté montre en direct où en est chaque jour :

CouleurSignification
NormalDe la place : posez sereinement.
Proche seuilÇa se remplit — si cette date compte pour vous, ne tardez pas.
Seuil atteintLe jour est plein : un souhait supplémentaire devra passer par l'arbitrage du staff.

Un quota de jours par personne s'applique aussi (affiché en haut) — il dépend de votre quotité de travail.

Comment ça se termine

Au staff, l'équipe arbitre les conflits éventuels (la priorité de groupe sert de règle de départage), puis le comité clique ✅ Valider et verrouiller : les saisies sont figées et deviennent le planning de vacances. Un e-mail récapitulatif de vos congés vous est alors envoyé, et ils apparaissent en lecture seule sur votre page Indisponibilités. Après verrouillage, tout changement passe par le comité.

Le système suit un cycle annuel. Côté comité, ce sont trois « assistants » ; côté MAR, cela se résume à trois moments où l'on attend quelque chose de vous :

09L'équité des gardes, expliquée

La répartition des gardes n'est pas faite à la main : un algorithme la calcule pour que chacun porte une part équitable de la charge, en particulier des gardes les plus contraignantes.

Les règles, dans l'ordre de priorité

  1. Week-ends (vendredi-dimanche) : l'écart entre MARs est réduit en priorité — c'est la charge la plus lourde.
  2. Samedis, puis jeudis : équilibrés ensuite.
  3. Total de gardes : équilibré en dernier.

Ce qui est pris en compte

  • Votre quotité : un MAR à 80 % a une cible de gardes proportionnelle (80 % de la cible d'un temps plein).
  • Vos indisponibilités et souhaits saisis à l'automne (section 06).
  • Noël et le Nouvel An : une rotation sur plusieurs années fait tourner ces gardes — celui qui a fait Noël cette année ne le refait pas l'an prochain. Les échanges réalisés en cours d'année sont enregistrés « au réel » pour que la rotation reste juste.

La vue 📊 Équité du planning montre les compteurs de chacun par rapport à sa cible : tout est visible par tous, c'est le principe.

Le certificat d'équité

En tête de la vue 📊 Équité, un certificat résume la situation d'un coup d'œil : un verdict (« Planning équitable — certifié » ou « À examiner »), le pourcentage de MARs à moins de deux gardes de leur cible, l'écart le plus élevé du service, et un petit graphique montrant que la grande majorité des MARs se situe tout près de sa juste part. C'est la preuve, chiffrée et consultable par chacun, que les écarts restent faibles.

Pourquoi Prunet n'apparaît pas dans le certificat

Un MAR au régime de souhaits garantis (ses mardis, par exemple) a pour cible ses jours choisis, et non une part d'équité classique : il est donc écarté du calcul du certificat pour ne pas fausser les chiffres. Ses gardes restent bien sûr visibles dans les compteurs en dessous.

Pour aller plus loin — la juste part, les protections, la rotation de Noël, la dette d'équité — le détail complet est dans un document dédié : L'algorithme des gardes, expliqué de A à Z.

Et si l'année se termine avec un petit écart ?

Personne ne tombe jamais pile sur sa cible. À partir de 2028, l'écart de fin d'année sera partiellement reporté sur l'année suivante (plafonné et amorti) : un MAR qui a fait un peu plus une année en fera un peu moins la suivante.

10Ressources : veille, protocoles, annuaire…

Veille bibliographique

La tuile « Veille biblio » du portail affiche les nouveaux articles parus dans les grandes revues d'anesthésie-réanimation (et les revues généralistes quand elles touchent nos thèmes). La sélection est automatique et se met à jour chaque semaine :

  • Seuls les articles « solides » passent le filtre : essais randomisés, méta-analyses, revues systématiques, recommandations.
  • Chaque article porte un badge de type et des étiquettes de thème (sepsis, voies aériennes, ALR…). Cliquez une étiquette pour filtrer.
  • Le tri par pertinence met en avant ce qui concerne le plus la spécialité.

Le CR d'anesthésie

Un outil pour rédiger vos comptes-rendus d'anesthésie plus vite : vous cliquez l'intervention, les intervenants et le déroulé (monitorage, induction, voies aériennes, ALR…) et le compte-rendu se rédige tout seul dans le volet de droite, prêt à copier-coller dans le DPI. L'ALR conseillée, l'antibioprophylaxie et le monitorage s'adaptent automatiquement au geste choisi.

  • Aucune donnée patient n'est saisie ni conservée : seuls la date, les intervenants et la technique d'anesthésie figurent dans l'outil.
  • Depuis le portail : la tuile « CR d'anesthésie ».
  • Depuis un poste du bloc (accès internet restreint) : l'outil s'ouvre directement, sans passer par le portail, à l'adresse chpg-anesthesie.github.io/Planning-CHPG/cr-anesthesie/ — à mettre en favori.

Protocoles, topos, staffs, annuaire, CRH

  • Protocoles : les procédures du service classées par spécialité, avec recherche plein texte.
  • Topos / biblio : les présentations et documents partagés du service.
  • Staffs à venir : le programme des réunions, avec dates et intervenants.
  • Annuaire : les numéros utiles de l'hôpital et les DECT, cherchables.
  • CRH : les comptes rendus de réanimation.

11Confidentialité & protection de vos données

Ce que le système enregistre — et ce qu'il n'enregistre pas

Uniquement ce qui sert à faire les plannings : votre nom, vos initiales, votre code d'accès, votre email professionnel et votre DECT, votre quotité de travail, et ce que vous saisissez vous-même (indisponibilités, congés, souhaits). Aucun nom de patient, aucune donnée médicale de patient n'est stocké dans le planning.

Un réflexe à garder

Dans vos saisies libres (motif d'indisponibilité, commentaire), n'écrivez jamais de nom de patient ni d'information médicale le concernant. Ces champs sont visibles du comité.

Chacun son code, chacun ses données

Votre code d'accès est personnel. Avec lui vous consultez le planning de l'équipe, et vous ne modifiez que vos propres indisponibilités et congés — le système vous empêche techniquement d'accéder à la saisie d'un confrère. Seul le comité voit l'ensemble : c'est indispensable pour construire les gardes, poser les absences validées et gérer l'équité. Même principe qu'un secrétariat de planning.

Où vivent vos données

Tout ce qui est personnel — indisponibilités, congés, email, DECT, code d'accès, détail des gardes — est rangé dans un compte Google professionnel protégé, auquel seul le comité accède. Les pages du site, elles, sont publiques comme n'importe quel site web : elles ne contiennent que la mise en page, jamais vos données, qui ne s'affichent qu'après saisie de votre code. À chaque connexion, la date et votre nom sont notés dans un registre technique (les 2 000 dernières), uniquement pour dépanner.

Vos droits

Vous pouvez à tout moment demander au comité de consulter, corriger ou supprimer les informations qui vous concernent. Une simple demande, à l'oral ou par email, suffit.

12Questions fréquentes

Je veux échanger une garde avec un collègue, comment faire ?
Mettez-vous d'accord entre vous, puis transmettez l'échange au comité, qui le saisit et publie. Votre bandeau « Mes gardes » se met à jour à la publication. L'échange est enregistré « au réel » — important pour la rotation Noël/Nouvel An.
Le planning que je vois est-il le définitif ?
Vous voyez toujours la dernière version publiée. Si le comité travaille sur une modification non publiée, elle n'apparaît pas encore. En cas de doute sur une garde imminente, demandez au comité.
J'ai raté la date limite des indisponibilités, que faire ?
La répartition automatique ne peut plus en tenir compte. Deux issues : proposer un échange de gardes une fois le planning publié, ou signaler au comité une contrainte majeure avant la génération s'il est encore temps.
Mon code d'accès ne fonctionne pas.
Vérifiez les majuscules (le code est en capitales) et les espaces avant/après. Sinon, demandez un renvoi de code au comité — vous recevrez un e-mail (vérifiez aussi les indésirables).
Un congé validé n'apparaît pas dans « Mes congés ».
La tuile reflète ce qui est saisi dans le planning : si un congé manque, c'est la saisie qui doit être corrigée. Signalez-le au comité avec les dates exactes.
Pourquoi ai-je plus de gardes que mon collègue ce trimestre ?
L'équité se juge sur l'année, pas sur un trimestre, et d'abord sur les week-ends. Ouvrez la vue 📊 Équité : vous y verrez votre position par rapport à votre cible (qui dépend de votre quotité). Un déséquilibre ponctuel se résorbe sur les mois suivants.
Puis-je marquer tous mes week-ends comme indisponibles ?
Non — un quota plafonne les indisponibilités, sinon la répartition équitable deviendrait impossible. Utilisez les 🚫 pour vos contraintes fermes et les ⭐ pour orienter le reste.
Le portail affiche des informations périmées.
Rechargez la page en forçant le rafraîchissement (tirez la page vers le bas sur mobile ; Ctrl+Maj+R sur ordinateur). Le portail garde une copie locale pour s'ouvrir vite ; ce geste force la mise à jour.
